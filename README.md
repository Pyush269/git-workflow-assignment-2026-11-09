# Git Workflow Assignment

A two-page HTML project created locally before its GitHub repository.

## Completed workflow

1. Initialize main and commit index.html and about.html.
2. Update the home page in a second commit.
3. Create and switch to feature, then commit learning outcomes.
4. Switch to main and merge feature with an explicit merge commit.
5. Ignore *.log and temp/, verified using local demonstration files.
6. Commit an experimental banner and undo it using git revert.
7. Document the Git commands, then push main and feature to GitHub.

Repository: https://github.com/Pyush269/git-workflow-assignment-2026-11-09

Open index.html in a browser to view the project. See git_commands.txt for every assignment Git command and its explanation. Ignored demonstration files remain local and are not published. The final PDF submission is stored separately from this repository.
